# RegexRiddle

## Avvio

1. Installa e avvia Docker Desktop.
2. Apri un terminale nella cartella del progetto.
3. Esegui:

```bash
docker compose up --build -d
```

Apri l'applicazione su http://localhost:5173.

Per fermarla:

```bash
docker compose down
```

Il primo avvio crea automaticamente il database e inserisce i dati dimostrativi inclusi nel progetto.
